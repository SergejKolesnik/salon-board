# Salon Board

Розклад косметологічного кабінету та безпечний журнал підтверджених вимірювань складу тіла — веб-застосунок на FastAPI.

## Вимірювання Withings

Після входу адміністратора відкрийте `/body` або кнопку **Вимірювання** у панелі адміністратора.

1. Оберіть наявного клієнта та відкрийте коротку сесію на салонній станції.
2. Новий вимір потрапляє у чергу та не додається до клієнта автоматично.
3. Працівник перевіряє відповідність клієнта і підтверджує запис.

Наразі кнопка тестового імпорту моделює надходження даних. Наступний крок — серверний Withings OAuth/webhook, який створюватиме таке саме pending-вимірювання. У браузер не потрапляють OAuth-токени чи Client Secret.

Перед запуском потрібно задати `TURSO_URL` і `TURSO_TOKEN` у змінних середовища. Орієнтир — `.env.example`; фактичні секрети ніколи не комітяться.

## Можливості

- **Сітка майстрів** — всі спеціалісти бачать навантаження один одного в реальному часі
- **Рецепція** може створювати, редагувати та видаляти записи
- **Перевірка конфліктів** — система не дозволить записати двох клієнтів на той самий час до одного майстра
- **Мобільний вигляд** — вкладки по майстрах, адаптований під телефон
- **Клік на слот** — форма одразу з заповненими часом і майстром
- **CRM клієнтів** — пошук і вибір клієнта, імпорт із контактів Android, єдиний формат українських телефонів і захист від дублів за номером
- **SQLite** — база створюється автоматично, без налаштувань

## Технології

- **Backend:** Python 3.10+, FastAPI, SQLite (вбудований)
- **Frontend:** Vanilla JS, HTML/CSS — вбудований в `main.py`, без збірки
- **Одна залежність:** `fastapi` + `uvicorn`

## Запуск

```bash
# 1. Клонувати
git clone https://github.com/YOUR_USERNAME/cosmo-schedule.git
cd cosmo-schedule

# 2. Встановити залежності
pip install -r requirements.txt

# 3. Запустити
uvicorn main:app --reload

# 4. Відкрити у браузері
# http://localhost:8000
```

База даних `cosmo.db` створюється автоматично при першому запуску з демо-даними (4 майстри, записи на сьогодні).

## API

| Метод | Endpoint | Опис |
|-------|----------|------|
| GET | `/api/masters` | Список майстрів |
| POST | `/api/masters` | Додати майстра |
| GET | `/api/appointments?date=YYYY-MM-DD` | Записи на дату |
| POST | `/api/appointments` | Створити запис |
| PUT | `/api/appointments/{id}` | Оновити запис |
| DELETE | `/api/appointments/{id}` | Видалити запис |
| POST | `/api/clients` | Створити клієнта CRM |
| GET | `/api/breaks?date=YYYY-MM-DD` | Перерви на дату |
